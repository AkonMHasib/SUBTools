SUBTools Developer & Architecture Guide

Complete authoritative technical documentation for SUBTools — the unified digital university suite for State University of Bangladesh. Covers mobile clients (SUBMobile & STC), web admin portal (SUBAdmin), serverless Cloud Functions backend, and Firestore database architecture.

📱
SUBMobile App

Native Android app built in Java/Kotlin. Serves students with offline class routines, shuttle bus tracking, push notices, blood donor registry, and PDF generator.

👔
STC Coordinator App

Dedicated Android mobile app for academic department coordinators to manage class routines, subjects, faculty schedules, and transport overrides on the go.

🖥️
SUBAdmin Web Panel

Single-page React web portal hosted on Vercel. Provides complete enterprise control, role-based access management (RBAC), ads cropping, and activity auditing.

Accuracy Guarantee
This documentation reflects the exact active implementation across repository codebases (`SUBMobile`, `STC`, and `SUBAdmin`). Features marked with Not Specified represent potential extensions not explicit in core source files.

System Architecture & Tech Stack

SUBTools follows a serverless cloud-native pattern. React frontend and Android native clients interface directly with Firebase Cloud Firestore for real-time reads, while privileged actions and external integrations route through Node.js Express REST API endpoints hosted on Firebase Cloud Functions.

Layer Technology Component Purpose / Description
Client App SUBMobile (Android Native Java) Student app providing offline routine caching, notices, bus tracking, cover page PDF generator.
Coordinator App STC (Android Native Java) Coordinator management client for modifying routine slots, subject lists, and bus daily overrides.
Web Admin SUBAdmin (React 19 + Redux Toolkit) Vite single-page admin portal deployed on Vercel with ImgBB aspect-ratio cropper.
Backend Firebase Cloud Functions (Node.js 24) Express REST API engine handling user directory list, admin invites, ban/unban, FCM dispatch.
Database Cloud Firestore (NoSQL) Real-time database storing routines, notices, transport, users, faculty, sublets, tuitions.
Media ImgBB API Third-party CDN storage for user avatars (1:1 ratio) and admin ad banners (16:9 & 16:5 ratio).

Roles & Permissions (RBAC)

SUBTools enforces an enterprise multi-role security framework. Every operational component evaluates user permissions dynamically.

Role Identifier Target Audience Granted Capabilities & Access Rights
super_admin System Lead / Super Admin 100% Unrestricted Access. Manages admin appointments, system settings, activity logs revert, custom ad banners, RBAC matrix, and database operations. Bypasses all sub-permission checks.
admin Department Admin Department-level administrative access. Manages department notices, routines, faculty listings, and student profiles.
coordinator Academic Coordinator Manages class routines, subject registries, faculty schedule assignments, and student directory for their specific department.
moderator Community & Transport Lead Moderates tuition posts, room sublet listings, lost & found submissions, and daily shuttle bus schedules.
student SUB Mobile User Read-only access to academic schedules, notices, shuttle tracking; student postings for blood donation, lost-found, sublet, and tuition finder.
Super Admin Identity Resolution
Super Admin status is granted if role === 'super_admin', roles array contains 'super_admin', Firebase Auth custom claims have super_admin: true, or user email matches verified admin identities (e.g. akonmhasib@gmail.com, subtools.admin@gmail.com, hasiburrahman@gmail.com, akonszone@gmail.com, or @sub.edu.bd domain).

REST APIs & Cloud Functions

Cloud Functions expose REST endpoints served under /api/* proxied via Vercel rewrites. All requests require a valid Firebase ID Bearer Token in the Authorization header.

HTTP Method Endpoint Path Min Role Description
GET /api/users Admin Returns merged directory of Firebase Auth users & Firestore profiles.
DELETE /api/users/:id Super Admin Deletes user from Firebase Auth and Firestore directory.
POST /api/users/:id/verify Admin Manually sets emailVerified = true in Firebase Auth and Firestore.
POST /api/users/:id/ban Super Admin Disables account in Firebase Auth and updates status to 'Banned'.
POST /api/invite-admin Super Admin Creates new administrative account using Firebase Admin SDK.
GET /api/activity-logs Super Admin Retrieves system activity logs ordered by timestamp desc.
POST /api/activity-logs/:id/revert Super Admin Reverts specified activity state (ban, verify, doc mutation).
GET /api/time Public Returns server timestamp and Asia/Dhaka date string.

ImgBB Image Cropping & Uploads

SUBTools uses ImgBB API for hosting image assets without bloat. Canvas-based cropping is performed client-side prior to API upload:

  • User Profile Avatars: Enforced 1:1 square aspect ratio (160x160 or 300x300 canvas).
  • Navigation Drawer Ads: Enforced 16:9 widescreen aspect ratio.
  • Homepage Main Ads: Enforced 16:5 banner aspect ratio.
JavaScript Client ImgBB Upload Request 
const uploadBlobToImgBB = async (blob, filename) => {
  const file = new File([blob], filename, { type: "image/jpeg" });
  const formData = new FormData();
  formData.append("image", file);
  
  const apiKey = "YOUR_IMGBB_API_KEY"; // Environment configured
  const res = await axios.post(`https://api.imgbb.com/1/upload?key=${apiKey}`, formData);
  return res.data.data.url; // Returns direct HTTPS CDN link
};

Academic System (Routines & Subjects)

The routine engine handles academic scheduling for all departments at State University of Bangladesh. Features include:

  • Multi-Step Routine Creator: Step 1 (Course Info) → Step 2 (Schedule, Term, Room) → Step 3 (Faculty Selection) → Step 4 (Conflict Detection & Confirmation).
  • Real-Time Conflict Detection: Scans target routines against room availability, teacher schedules, and time overlap.
  • Routine Types: Supports Regular slots and Temporary Shift slots (color-coded chips on cards).
  • Bulk Import: Imports batch routine definitions via validated JSON payloads.

Transport & Bus Tracking

Shuttle bus management provides real-time route inspection, seating capacity indicators, and Obhai VTS GPS integration.

  • QR Code Generator: Dynamically generates tracking QR codes for bus boarding terminals.
  • Midnight Automated Reset Cron: Cloud Function resetBusOverridesScheduled runs nightly at 00:00 Asia/Dhaka to revert temporary daily driver/route overrides back to default baseline.

Notices & FCM Push Notifications

Official university announcements support rich text descriptions and verified PDF links (restricted to Google Drive and Microsoft OneDrive URLs).

When a notice document is created in Firestore (notices/{noticeId}), the onNoticeCreated Cloud Function trigger fires automatically, gathering active device FCM tokens from fcmTokens and users collections to dispatch push notifications via Firebase Admin Messaging.

Community Modules

Student utility modules facilitate campus life collaboration with moderation workflows:

  • Lost & Found: Item reporting with image attachment, category tags, and status updates (Pending, Approved, Claimed).
  • Room Sublets: Student sublet & hostel vacancy listings with contact details and admin approval.
  • Tuition Finder: Student tuition post opportunities moderated by Super Admins.
  • Blood Donor Registry: Emergency blood donation lookup by department, city, area, and blood group.

Cover Page PDF Generator & Quotes

  • Assignment & Lab Report Cover Page PDF: Generates downloadable PDFs adhering to official SUB formatting guidelines directly inside the mobile app. Usage statistics are logged to coverPages Firestore collection for analytical reporting.
  • Scheduled Daily Quotes: AlarmManager triggers 4 daily notifications at 6:00 AM, 12:00 PM, 6:00 PM, and 12:00 AM. Seeds 225+ curated quotes (Love, Education, Motivation, Success, Rumi, Imam Ali, Classical Wisdom, and Movie/Series lines) into Room DB offline cache.

Mobile Apps (SUBMobile & STC)

Built natively in Java/Kotlin for Android. Uses Architecture Components (LiveData, ViewModel, Room DB, Navigation Component, ViewBinding, Glide, Material Components).

Lifecycle Context Safety Rule
All asynchronous callbacks (Firebase / Retrofit / Dialog Fragment dismissals) verify isAdded() && getContext() != null before executing UI modifications to prevent IllegalStateException: Fragment not attached to a context.

Admin Panel (SUBAdmin)

Built with React 19, Redux Toolkit, React Router v6, TailwindCSS, and Axios. Features custom glassmorphic styling, responsive drawer navigation, dark/light theme switching, and live user session sync.

Security & Troubleshooting

401 / 403 Authorization Failure Resolution
If an API request returns 401 or 403 on Vercel:
  1. Ensure apiClient.js attaches await auth.currentUser.getIdToken() to fresh request headers.
  2. Verify user email is present in server-side SUPER_ADMINS list or Firestore users/{uid} document has role: 'super_admin'.
  3. Confirm Firestore rules contain global match-all permission: match /{document=**} { allow read, write: if true; }.

Common Troubleshooting Index

Issue / Symptom Likely Root Cause Resolution Step
Fragment requireContext() crash Async callback executed after Fragment detached Wrap callback in if (isAdded() && getContext() != null) and use dismissAllowingStateLoss().
Vercel API 404 Route Not Found Missing vercel.json rewrite rule Ensure vercel.json rewrites /api/(.*) to Firebase Cloud Functions URL.
Bus Schedule Overrides Not Resetting Cloud Functions cron trigger paused Verify resetBusOverridesScheduled function deployment and Asia/Dhaka timezone setting.
